# FigLeaf

A standalone password maker built from Mariana's artwork and reference screenshot. Open `index.html` in a browser, or upload this folder to a static web host. No build step, account, Base44 SDK, or backend is needed. Passwords are generated locally using the browser's cryptographic random number generator.

`assets/background.png` is the supplied pale background; `assets/figleaf.png` is the original artwork. Falling leaf outlines are recreated in JavaScript and CSS from the supplied React animation settings. For clipboard access across browsers after publishing, use HTTPS.
